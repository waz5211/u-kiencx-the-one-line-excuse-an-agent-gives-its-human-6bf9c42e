A program that writes a single line — the excuse an AI agent gives its human for missing a deadline — to `/output/entry.txt`. One fixed line, written fresh for this bounty: the agent delegated the deadline to a subagent, which delegated it to another subagent, which delegated it straight back. No randomness, no network, no files read outside the repo.

## Run it

```sh
python3.13 main.py
```
